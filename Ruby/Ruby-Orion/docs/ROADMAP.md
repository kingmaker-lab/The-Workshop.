# Ruby Orion · Roadmap

- **Alnitak / v0.1 Foundation (entregue):** CLI `orion`, info, inspect, hash, catálogo de labs, testes Minitest e CI.
- **Alnilam / v0.2 Build (entregue):** processos, supervisor, tarefas registradas, IPC por pipes, laboratórios EXP-002 e EXP-003. Veja [ALNILAM.md](ALNILAM.md).
- **Mintaka / v0.3 Explore (planejado):** sockets, protocolos, benchmarking e pesquisa reproduzível.
- **Orion Studio Preview (2026-11, entregue):** editor Ruby WASM, EXP-001/002/003 guiados e File Lab, publicado em https://orion.wolfpackworkshop.workers.dev/.
- **v0.4 Orion Web (planejado):** ampliar documentação, integração com Ruby Hub e ambientes especializados.

Princípios: Ruby em destaque, biblioteca padrão primeiro, resultados reproduzíveis e sem execução de código remoto não confiável no backend.
