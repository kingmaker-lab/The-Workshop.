# Ruby Orion · Roadmap

- **Alnitak / v0.1 Foundation:** CLI `orion`, info, inspect, hash, catálogo de labs, testes Minitest e CI.
- **Alnilam / v0.2 Build:** processos, automação, gems reutilizáveis e laboratório de IPC.
- **Mintaka / v0.3 Explore:** sockets, protocolos, benchmarking e pesquisa reproduzível.
- **v0.4 Orion Web:** documentação navegável e integração aprofundada com Ruby Hub.

Princípios: Ruby em destaque, biblioteca padrão primeiro, resultados reproduzíveis e nada de executar código remoto não confiável no backend.
