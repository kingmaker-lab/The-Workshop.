04 / FONTES & ESTRUTURA

Conheça a entrada. Entenda a saída.

Formatos públicos e exemplos de configuração, sem expor dados de produção.

JSONL / AUTENTICAÇÃO / EXEMPLO
{
  "timestamp": "2026-10-02T13:36:14Z",
  "source": "linux",
  "event": "authentication",
  "src_ip": "192.168.1.50",
  "user": "root",
  "result": "failed"
}

Os registros são lidos localmente. Não envie arquivos com credenciais, dados pessoais ou endereços internos para ferramentas públicas.

CONFIG / BASELINE EXPERIMENTAL
anomaly:
  enabled: false
  metrics: [orig_bytes, resp_bytes]
  minimum_samples: 20
  z_threshold: 4.0

Detecção estatística desativada por padrão; o limiar compara desvios da baseline, não a probabilidade de um ataque. A baseline é reiniciada a cada execução.

Que formatos de log são aceitos?

JSONL com eventos normalizáveis, syslog para eventos de autenticação e Zeek conn.log em JSON via --format network. A opção auto reconhece arquivos .log/.syslog como syslog e os outros como JSONL.

Como as regras YAML funcionam?

As condições são comparações explícitas de campos do evento, acompanhadas de nome, severidade e pontuação. O exemplo padrão observa autenticação bem-sucedida do usuário root.

rules:
  - name: privileged_successful_authentication
    event: authentication
    conditions:
      user: root
      result: success
    severity: high
    score: 30
O que a API HTTP disponibiliza?

Somente leitura, vinculada a 127.0.0.1:8765 por padrão: GET /health, GET /alerts?limit=100 (1 a 500) e GET /timeline?limit=500 (1 a 2000). A API não possui autenticação e não deve ser publicada na Internet.

05 / QUICK START

Reproduza no seu próprio ambiente.

Os comandos devem ser executados na raiz do repositório clonado. A análise usa apenas o arquivo sintético incluído no projeto.

01 / DEPENDÊNCIA & ANÁLISE
python -m pip install -r argus/requirements.txt
python -m argus.main analyze \
  argus/samples/ssh_bruteforce.jsonl

O motor produz alertas em JSON no terminal e salva os registros no banco SQLite local configurado.

02 / INVESTIGAÇÃO & API LOCAL
python -m argus.main timeline \
  --src-ip 192.168.1.50

python -m argus.main serve

Use a timeline para estudar a sequência e a API de leitura somente no loopback. Não é necessário nenhum serviço em nuvem.

Atenção: esta página não possui um console remoto. O comando serve inicia um processo local, sem autenticação HTTP.
06 / LIMITAÇÕES & SEGURANÇA

Conhecer os limites também é pesquisar.

O ARGUS é um laboratório defensivo experimental. Uma pontuação não substitui análise humana nem controles de segurança.

GATE / REDE

API restrita ao loopback

O servidor local não implementa autenticação nem rate limit por cliente. Exposição pública requer arquitetura própria e revisão de acesso.

GATE / PRIVACIDADE

Logs podem ser sensíveis

Proteja permissões, retenção e backups do SQLite. O site estático não envia arquivos para a nuvem.

GATE / ANÁLISE

Falsos positivos existem

Janelas, ordem temporal, drift, dados incompletos ou uma baseline contaminada alteram a interpretação dos sinais.

GATE / ESCALA

Ingestão ainda limitada

Não há limites abrangentes para tamanho de arquivo e cardinalidade de fontes. Testes de carga e de resistência a entradas hostis estão pendentes.

GATE / PERSISTÊNCIA

Estado de correlação volátil

Os eventos e alertas são armazenados, mas o estado temporal das correlações e a baseline não persistem entre execuções.

GATE / PUBLICAÇÃO

LAB ONLY

O motor defensivo não é oferecido como serviço web. A página pública mostra somente documentação e dados demonstrativos.
