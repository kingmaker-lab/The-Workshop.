// 01 — DISSECTING THE TRANSPORT

A anatomia de uma conexão.

O laboratório atravessa as principais syscalls da camada de transporte, desde a criação do socket até o encerramento da conexão.

01 / CREATEsocket()AF_INET · SOCK_STREAM
02 / ATTACHbind()127.0.0.1:8081
03 / WAITlisten()backlog · fila
04 / CONNECTaccept()novo descritor
05 / EXCHANGErecv() / send()bytes · close()

TCP é um fluxo de bytes. O protocolo de uma linha é definido por nós, não pelo TCP. Uma leitura não equivale necessariamente a uma mensagem completa.

// 03 — WHY IT MATTERS

Pequeno código.
Grandes lições.

Uma fundação segura começa entendendo as diferenças entre transmissão, delimitação, validação de entrada e encerramento.

01 / STREAM↔

Bytes não são mensagens.

O cliente pode fragmentar a entrada. Nosso protocolo delimita a mensagem por LF, acumulando bytes até completar a linha.

02 / LIMITS⌁

Limites explícitos.

512 caracteres ASCII por linha, timeout por operação, validação e descarte limitado de dados incorretos.

03 / FAILURE!

RST no mundo real.

Fechar um socket com entrada pendente pode ocultar a resposta de erro. O problema apareceu nos testes e virou aprendizado documentado.
