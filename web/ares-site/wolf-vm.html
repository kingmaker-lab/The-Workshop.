WOLF-VM

Uma máquina virtual de bytecode criada em C11. Registradores, instruções, pilha, memória e o ciclo Fetch → Decode → Execute. Nada de rodar uma distro: aqui, construímos o processador virtual.

v0.1 · LABORATÓRIOC11 + PYTHON 317 TESTES LOCAIS

Dentro da CPU

Oito registradores de 32 bits, PC, SP, flag zero, 64 KiB de memória de dados, código com cabeçalho WVM1 e saltos validados.

Construir e testar

Compile o interpretador, monte o bytecode WVA e observe cada transição com --trace. O código é um experimento educacional, não uma sandbox para cargas hostis.

// 001 — Primeira execução

MOVI R0, 5
MOVI R1, 3
ADD  R0, R1
HALT

; resultado esperado: R0 = 8

// Ciclo experimental

Estado e registradores → Memória → ISA → Decoder → Execução → Stack → I/O controlado → Debugger → Hardening → Benchmarks.
