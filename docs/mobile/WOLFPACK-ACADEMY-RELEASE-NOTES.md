# Wolfpack Academy v0.2.0 (Android)

Versão beta para distribuição direta através da The Workshop Mobile.

- 25 missões educativas offline nas trilhas Lógica, Caça aos Bugs e Fundamentos da Web.
- 5 níveis, XP por missão única e conquistas locais.
- Sem cadastro, anúncios ou envio de progresso para servidores.
- APK assinado para instalação direta; AAB disponível para eventual publicação em loja.

Verifique o SHA-256 do arquivo baixado usando o `SHA256SUMS` anexado e a assinatura do APK. O aplicativo está em beta e pode apresentar problemas.

**Compatibilidade:** APKs debug anteriores do GitHub Actions podem ter sido assinados com chaves distintas. Uma atualização direta sobre essas versões pode falhar; desinstalar normalmente apaga o progresso local.

A distribuição limitada gratuita do Android Developer Console é um cadastro separado do Google Play Console e requer autorização dos dispositivos participantes.
