# ATH-003 ARCHIMEDES | prospective design draft
Not a locked preregistration; finalize after pilot, before untouched confirmation. Primary question: at what actual incremental workload cost does ICARO beat matched native FULL? Let DeltaT=T_adaptive-T_full. Under identical common cost and constant expensive-stage unit cost e, DeltaT=H-(n-k)e, with H measured incremental selection/observation/control overhead; break-even e>H/(n-k) when k<n. In real systems H and e can depend on batch, device, cache, contention; measure instead of assuming linearity.
## Pilot matrix
Batch 32,64,128,256; announced b=8,16,24,32; deterministic cheap and expensive feature kernels with varying actual work (1,4,16,64,256 bounded repeats, check correctness and compiler elimination); vary correlation between cheap margin and incremental benefit, include adverse case. No artificial system pressure on constrained laptop. Same compiler, input representation, data validation, safety and output contract. Compare full native, cheap-only, fixed budget causal threshold, random feasible same-count, global top-k (total budget only, label prefix violations separately), ICARO prefix rank, optional exact small oracle (diagnostic only, cannot use labels in deployed policy). Separate fixed-budget selection from live observer. Include equally optimized static small model for quality-matched baseline. Measure both resident and true end-to-end feature generation paths; expensive work genuinely skipped for unselected samples, verify checksums/outputs; no padding loops advertised as real task. Include zero observer and common observer arms to isolate overhead.
## Statistics and gates
Pilot separate seed IDs and sessions from confirmation; five fresh sessions per available device as initial planning minimum, use pilot variability to set and freeze final counts. Randomize or counterbalance order within session, warm up, pair identical inputs; log all invalid runs/aborts, no ad hoc removal. Per-session CPU ratio and paired quality difference, report confidence intervals resampling independent units (sessions and seeds within design, not naive sample independence); noninferiority upper one-sided 95% bound on FULL minus ICARO <=1 pp; CPU superiority upper one-sided bound on ratio <1. Require both for primary claim, specify workload and batch in locked protocol; exploratory grid not confirmation. Report all grid cells, multiplicity strategy (Holm for secondary confirmatory tests or descriptive only), wall p50/95/99, separate-process peak RSS, joules only with validated instrument. Safety floor 512 MiB, stop >=80 C, no sudo, no pressure generation, record missing sensors. Separate hardware claims; N4020 first, ARM and other devices later; no extrapolation.
## ATLAS preparation
Candidate real dataset: UCI Smartphone-Based Recognition of Human Activities and Postural Transitions (raw inertial signals), https://archive.ics.uci.edu/dataset/341/ . Subject-disjoint train/calibration/test, freeze split and preprocessing, label mapping and multiclass metric before test, use raw input to measure avoided extraction. Check license, checksum, data leakage, class imbalance, and compare equal quality. No download or training yet.
