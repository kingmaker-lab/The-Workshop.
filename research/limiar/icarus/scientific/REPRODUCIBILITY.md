Freeze commit/tag, compiler and flags, source and binary SHA256, raw output SHA256, seed namespace, dataset version/license/split, hardware and affinity, OS/kernel, thermal and memory telemetry, test log, order and warmup, interruption/exclusion records, analysis code version. Separate raw immutable records from derived tables. Avoid machine identifiers or sensitive telemetry. Do not publish raw data without provenance and permission. Archive artifacts with manifest and license; DOI and peer review pending. Existing final JSON is not included yet. No release or DOI created.
For independent reproduction: clone exact revision; build per EXP-00X README; record compiler, test results, safety preflight; run pilot then fixed final protocol on new session; compare deterministic aggregate outputs only when input and budgets match, timing via tolerances/intervals not exact equality. Report failures. ACM artifact criteria are a target, not a badge already awarded.
