# ATH-001 BENEFIT-03 | ARGOS
Exploratory offline delayed-feedback simulation. Not Argus Project. METIS demonstrated stable context gains and reversal failure; do not alter previous code or criteria.
## Fixed protocol
HORIZON only (64 rows, 27 expansions, 1012 logical terms/batch). 4 forced audit expansions included in the 27 (not additional); 23 remaining expansions selected by priority subject to residual nested quotas. Audit positions drawn uniformly one per stratum [2,16),[16,32),[32,48),[48,64), zero-based. First two positions cannot be expanded at this budget; all other positions have known nonzero inclusion probability. Contract audits: residual capacity q_i-|A intersect P_i|, tighten to suffix minimum; heap chooses maximum feasible count then max priority. All audited arms output full predictions on audits; offline baselines have no audits. Compare audit_margin and audit_metis to unaudited arms to isolate opportunity cost; compare ARGOS to audit_metis at same audit/cost. All arms use same audit positions. Logical term count excludes model fitting, monitor, labels, heap etc.
## Feedback and policy
Only audit rows and labels delivered after 4 batches; no target distribution flag passed to policy. No-feedback arm never delivers labels and freezes initial choice; deliberately no guarantee. Monitor estimates plain-context vs plain-margin paired accuracy gain using Horvitz-Thompson weighting: strata widths 14,16,16,16 multiply observed gain g_i*(I_context-I_margin), divide by 64 and multiply 100. Conditional unbiased for fixed batch and model when audit independent, not a guarantee of realized audited policy advantage. Window 8 delivered batches, threshold +0.25 pp to choose context else margin; before window initial gate. No formal sequential risk guarantee. Refitting arm uses older 16 delivered batches (64 audit rows) for model fit, newer 8 for gate; reassesses on every 8 delivered batches once 24 available. Sparse nonuniform sample (first two positions excluded); exploratory, not unbiased model fit. Prior to refit uses original monitor, refreshed as feedback arrives. No external label service or actual latency measured. Full features generated offline, no production deployment.
## Stream
64 batches per seed/scenario, separate 2048 fit and 32*64 gate source rows. Stable IID, stable context, abrupt reversal t>=24, gradual reversal mixture from t16 to t40, recurring reversal t16-31 and t48 onward, abrupt with no feedback, context emergence t24 after IID. Reversal swaps conditional tail scales; cheap inputs same distribution. Separate seeds per scenario, not same-fit paired shift comparisons. Labels synthetic. Smoke 2299; pilot 2301..2319 odd. 70 runs, 4480 held-out batches, 286720 test rows, 31360 arm evaluations (excludes FULL/LITE and gate), 143360 fit and 143360 gate rows. 17920 audit selections per audited arm, shared sampled indices, 4-batch delay means last 4 batches' feedback not consumed. No artificial pressure, inherited 512MiB/80C safety, no sudo.
## Outcomes
Primary descriptive: abrupt post-change t24..63 ARGOS vs audit_metis (compute from events), report stable regressions and all scenarios/phases. Secondary refit, first margin delay (not sustained recovery; null if never), false fallback under stable context, emergence, audit opportunity cost, net accuracy against unaudited margin/metis; report intervals by seed exploratorily. No claim of actual CPU savings, drift detection guarantee or novelty. No tuning on pilot and calling it confirmation. Record raw hash, revision, test logs. Tests authored, execution pending.
