## Protocol frozen for this exploratory wave
Separate fit (2048 rows), gate validation (32*64=2048 rows) and test (24*64=1536 rows) per seed/scenario, disjoint RNG seeds. Smoke 2199; pilot 2201..2219 odd, no reuse of BENEFIT-01 seeds. Fit and gate observe source labels only; held-out policies use cheap features only; test labels used exclusively for offline evaluation and diagnostic oracles. Gate selects context per budget when validation mean gain >=0.25 pp and both chronological halves positive; otherwise margin. These thresholds are design choices, not statistically calibrated guarantees. No online labels or adaptation. Fixed gate per seed/scenario/budget. Five source->target conditions: IID->IID, heteroskedastic->heteroskedastic, heteroskedastic->IID, heteroskedastic->reversed (swap conditional tail scales), IID->heteroskedastic. Source/target names do not enter the deployed priority/gate. Conditional shift can be invisible to cheap-feature distribution; no claim of detecting it. Source calibration is independent per scenario, so do not treat shift differences as identical-fit paired comparisons; method comparisons within scenario are paired.
## Arms
Fixed maximum feasible cardinality: margin, benefit_margin, benefit_context, metis, random, exact-count label oracle. Variable: risk_context permits only estimated net gain >=.02 and estimated harm <=.10, then maximizes feasible eligible count and estimated gain; harm uses smoothed training frequency, not a calibrated risk guarantee. This is a separate ablation, not the gate combined with variable control. Match its realized expansion count using margin, context and label oracle. oracle_variable selects positive realized gains under prefix quotas, upper bound for at-most-budget quality; diagnostic only. Variable arms may use less even at b32; fixed arms must match FULL there. Report realized harms, correction counts, exact term equality, prefix violations and quality vs FULL. Labels never select operational arms. All features and both predictions are generated offline: terms are a logical cost proxy, not CPU/energy savings. Python heap, not compiled C runtime.
## Evaluation
Primary descriptive contrast at HORIZON: METIS vs margin on each stable condition; shift contrasts and risk arms secondary exploratory. Report all budgets and scenarios; paired per-seed differences; no declaration of statistical superiority or noninferiority. A future frozen confirmation with new seeds and independent data is needed. No tests on production workloads. Pilot 50 seed/scenario runs, 102400 fit rows, 102400 gate rows, 76800 test rows, 1200 held-out batches, 52800 selector evaluations (11*4*1200; excludes FULL/LITE and gate). One machine, no pressure generation. Safety before fit/gate/test batches, inherited 512 MiB/80 C limits, no sudo. No telemetry series recorded; peak RSS entire harness only.
