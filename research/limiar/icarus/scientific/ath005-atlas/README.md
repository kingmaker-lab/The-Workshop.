# ATLAS-01 MOTION — real-signal feasibility pilot
Exploratory, not a transfer of GAUSS confirmation. UCI HAR (dataset 240, Anguita et al., 2013; https://archive.ics.uci.edu/dataset/240/humanactivityrecognitionusingsmartphones). Use official v1 inertial signal files, not precomputed 561-feature vectors. Signals already filtered/windowed at 50 Hz (128 samples, 50% overlap). Six channels: total acceleration xyz and body gyro xyz. Official 21/9 subject train/test split; highest six subject IDs in official train used exclusively for calibration, remaining 15 for fitting. No random window split; do not tune on test. Dataset locally obtained, not redistributed. Verify archive source and retain SHA-256. Smoke uses first two calibration batches, never test outcomes.
Model: six-class standardized nearest centroid, population variance floor 1e-8, fitted once on fit subjects; shared additive distances. Cheap six per-axis means; expensive 24 variance and lag 1/8/32 squared-difference averages, actually computed only on expansion. Same weights/model and native kernel for FULL, LITE, STATIC, CAUSAL. Cheap margin = second-smallest minus smallest distance, exact quota floor(n*q/4), q=1,2,3, prefix constraint floor(i*q/4); causal uses current margin, known batch size and forced final fill. Calibrate thresholds on independent calibration subjects (quantiles 5..100%, zero and nextafter(max), ties smallest) separately per budget; select maximum pooled correct. Contiguous batches up to 64, never cross subject boundaries; retain source order, not assumed chronological. All nine test subjects, 2,947 windows. Overlap means windows are not independent; report subject-wise confusion matrices, pooled and subject-mean accuracy, geometric CPU ratio across subjects using sums of per-batch median CPU. Five paired randomized repetitions per budget/arm, smoke three. Full and lite measured for every budget, warmup checks predictions and mask, prefix, count, features. No formal 1pp noninferiority or multiple-testing claim; no selection of successful cells as confirmation. No RANK in first real pilot: streaming causal versus equal-count STATIC is primary exploratory comparison. No fabricated work or sleep inside native timing; timing excludes parsing, sensor acquisition/filtering, Python, allocation/packing, training/calibration, safety and I/O. Feature count not identical to arithmetic cost. Buffer max 64*768*8 bytes = 0.375 MiB, Python extra; no external dependencies. Passive safety guard from ARGOS 256 MiB / 80 C before batches/repeats and during fitting, not continuous. Atomic hashed batch checkpoints lock source files/model/config/revision/binary; resumed timing may span sessions. Overall process RSS only, not per-policy memory. No sudo, no pressure. Test compiled/run locally pending. ATLAS-02 will consider unfiltered raw HAPT dataset 341, per-policy memory, end-to-end and other hardware.
## Run
Download official dataset from UCI page, extract outer zip and inner UCI HAR Dataset.zip if present. Set data path to folder containing train/ and test/ directly. Do not copy datasets into git. From this directory:
```sh
nice -n 10 cc -std=c11 -O2 -Wall -Wextra -Werror -fPIC -shared -ffp-contract=off atlas.c -o libatlas.so -lm
nice -n 10 python3 atlas.py --data "$HOME/datasets/UCI HAR Dataset" --smoke --checkpoint .atlas-smoke --output atlas-smoke.json
nice -n 10 python3 atlas.py --data "$HOME/datasets/UCI HAR Dataset" --checkpoint .atlas-pilot --output atlas-pilot.json
```
Only proceed after smoke. Retain source archive hash, compiler/version, raw outputs and checkpoints. No pull/recompile between interrupted runs. No test-driven changes to candidate; later modifications require fresh evaluation or clearly exploratory status.
