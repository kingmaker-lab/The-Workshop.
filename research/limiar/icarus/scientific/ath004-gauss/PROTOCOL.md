## Fixed design and inference
Five blocks (sessions 1..5), 24 fresh seeds per block (3001..3120 disjoint), one test batch of 256 per seed, seven timed repeats and four arms, randomized paired order, one warmup per arm. Smoke seed2999 separate, three repeats. Total 30,720 independent-generator test rows, 491,520 calibration rows, 3,360 timed calls plus 480 warmups, no sample multiplication by repetitions. Each block executed in distinct actual measurement sessions on same device, separated in time with normal idle conditions. Do not run in parallel or create artificial pressure. Record session context externally; identifiers alone do not establish temporal independence. Resume interrupted groups with same revision and binary; preserve invocation log, no selectively discarding slow groups. Resumed blocks are disclosed as such. If conditions materially change, report limitation, no automatic substitute block. No early stop on favorable data, no post-hoc sample extension or threshold adjustment. 5 blocks chosen as a low-resource fixed design, not power-validated; inconclusive possible.

For each seed, quality loss =100*(FULL correct-CAUSAL correct)/256. Timing log ratio=ln(median CAUSAL CPU / median FULL CPU), seven repeats. Average both equally over 24 seeds in block; average block means over five blocks; one-sided approximate Student t upper bound mean+t(0.95,4)*SD/sqrt(5), t=2.13184678632665. Exponentiate log bound for geometric CPU ratio. Primary intersection-union decision: both upper quality loss <=1 pp and upper CPU ratio <1. Strong aspirational target additionally upper CPU ratio <=0.5, reported separately, nested. No multiplicity correction needed for conjunctive primary claim; no confirmatory claims for secondary arms. Approximate t inference with only five blocks relies on independent representative block means and approximate normality, not guaranteed coverage. No switching to alternative analysis after results. Report estimates and bounds even when criterion fails; failure to establish noninferiority is not proof of inferiority. No cross-hardware generalization.

## Safety and resources
Retain 256 MiB passive available-memory floor and 80 C stop from LEVER as explicit amendment to older prospective 512 MiB draft for this bounded workload. No elevated privileges, new dependencies, or artificial pressure. Single process, ~0.88 MiB raw input buffer; calibration and Python require additional memory. Checks sampled, not continuous. Native CPU timing excludes Python, calibration, input generation, observation and I/O. No end-to-end claims. Atomic hashed checkpoints per seed; manifest locks revision, binary, protocol, session config. Record all interruptions; resume same command after safe conditions. Keep logs and original data. Do not overwrite results from prior valid run. No actual compile/test or confirmation at publication.
