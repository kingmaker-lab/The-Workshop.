# EXP-002 FEATHER
Research only. Prototype; target hardware measurements pending.

Hypothesis: a cheap first-stage margin can select easy samples for early exit and reduce mean evaluated feature terms with <=1 percentage point accuracy loss versus full scoring. Target >=30% feature-term reduction (not CPU reduction).

Synthetic fixed linear classifier: 32 Gaussian features, first 4 weighted 1.0, remaining weighted .15; labels generated by full linear rule plus Gaussian noise. No fitting; this deliberately favorable toy distribution is not evidence for real-world tasks. Compare full, lite (4 terms), and dynamic. Margin is a heuristic, not calibrated probability. Generate independent calibration and holdout samples for each of five fixed seeds. Choose threshold on calibration only, minimizing mean terms subject to <=1 pp accuracy loss; infinity fallback. Report holdout paired metrics and all seed results; no holdout tuning. Report accuracy, early exits, mean feature terms, raw CPU timing and median (3 rotated runs, warmups). Feature terms are a proxy, not total instruction count or energy. Data generation excluded from timings; input features already resident, no feature acquisition cost modeled. Timing is exploratory, includes evaluation overhead. Compare dynamic vs lite as well; no novelty claims.

Run from this directory:
```sh
python3 -m unittest -v
python3 feather.py > feather-local.json
```
Record commit SHA, Python version, hardware/OS, power and thermal context separately. WAX baseline is not replaced. Default 3000 samples per split, 5 seeds. No dependencies or elevated privileges. No results yet.
