05 / HEART_005 / CAUSAL ATTENTION
Causal Attention Playground.
Explore a matriz de atenção de uma sequência. A linha representa o token que consulta (Q), e cada coluna representa um token observado (K). O triângulo superior fica bloqueado: nenhuma posição vê o futuro. A implementação Python usa embeddings do HEART_004; este visualizador usa vetores e projeções determinísticos não treinados, independentes dos pesos Python e do exemplo HEART_004. Não gera texto nem envia dados à rede.
■ intensidade do peso· atenção ao futuro bloqueadaQ/K IDs de tokens BPE
HEART_005 implementa apenas uma cabeça de atenção escalonada com softmax e codificação posicional senoidal. As matrizes Q/K/V são inicializadas por seed e não foram treinadas. A atenção causal não representa compreensão da linguagem; Transformer, backpropagation e inferência autoregressiva ficam para etapas futuras.
